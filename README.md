# คุณหมูทวง V.2 (KhunMoo Tuang) / คุณไก่ทวง V.2 🐷🐔
### ระบบบริหารจัดการชั้นเรียน & ทวงงานอัจฉริยะ (React + LINE OA + Gamification)

แอปพลิเคชันจัดการชั้นเรียนครบวงจรที่พัฒนาด้วย **React 19 + TypeScript + Tailwind CSS** ออกแบบตามรูปแบบอินโฟกราฟิก **"สรุปไก่ทวง V.2"** และ **"คุณหมูทวง"** พร้อมเชื่อมต่อ **LINE Messaging API / LIFF** และระบบเกมฟิเคชันกระตุ้นการเรียนรู้

---

## 🚀 ฟังก์ชันหลักที่พัฒนาเสร็จสมบูรณ์

1. **จัดการชั้นเรียนได้ถึง 6 ขั้นตอน (6-Step Pipeline):**
   - **มอบหมาย:** สร้างการบ้าน กำหนดวันส่ง เกณฑ์ Rubrics และคะแนน
   - **ทวงงาน:** ระบบส่ง LINE Push Notification ทวงงานรายคน หรือทวงคนค้างส่งทั้งห้อง
   - **ตรวจงาน:** ตรวจงานอย่างรวดเร็ว พร้อมตัวกรอง ส่งตรงเวลา / ส่งช้า / ยังไม่ส่ง / ตรวจแล้ว
   - **แจ้งผล:** ยิงผลคะแนนและข้อเสนอแนะกลับไปหานักเรียนผ่าน LINE OA หรือ Student Portal
   - **เข้า Drive:** จัดระเบียบชิ้นงานของนักเรียนเข้าโฟลเดอร์คลาวด์ พร้อมดาวน์โหลด
   - **ทำคะแนน:** สรุปคะแนนรวม คำนวณเกรด และ **Export ไปยัง CSV / Google Sheets** ได้ในคลิกเดียว

2. **มี AI เป็นผู้ช่วยตรวจงาน (AI Grading Assistant):**
   - วิเคราะห์เกณฑ์ Rubrics อัตโนมัติ สรุปจุดเด่น (Strengths) และจุดที่ควรพัฒนา (Suggestions)
   - แนะนำคะแนนที่เหมาะสม พร้อมข้อความให้กำลังใจนักเรียน
   - รองรับการเชื่อมต่อ **Google Gemini API Key** จริง หรือใช้งานผ่าน **Smart Heuristics Engine** ในตัว

3. **ส่งงาน / ตรวจงานเขียนบนรูปได้ (Canvas Annotation Tool):**
   - ปากกาวาด ไฮไลต์ ยางลบ ปรับขนาดหัวปากกา และพาเลตต์สี
   - สแตมป์สติ๊กเกอร์ประทับตรวจ: `💯 เต็มสิบ`, `⭐ ยอดเยี่ยม`, `✏️ แก้ไข`, `🐷 ตรวจแล้ว`, `🐔 ผ่านฉลุย`
   - บันทึกการตรวจทับบนรูปภาพชิ้นงานของนักเรียนทันที

4. **ระบบ Gamification (สะสมไข่ / สัตว์เลี้ยง / EXP):**
   - ส่งงานตรงเวลาได้รับ **+15 EXP** และ **ไข่สุ่มนำโชค 🥚**
   - ระบบเคาะไข่ 3 ครั้ง (3-Tap Hatching) พร้อมเอฟเฟกต์ Confetti และเสียงดนตรีเฉลิมฉลอง
   - ปลดล็อกสัตว์เลี้ยงน่ารักระดับ Common, Rare, Epic, Legendary

5. **ระบบสอบ Anti-cheat Guard (รู้ทันทีเมื่อเด็กออกจากหน้าจอ):**
   - นาฬิกาจับเวลานับถอยหลัง
   - ตรวจจับ `visibilitychange` และ `window.blur` แบบเรียลไทม์
   - เมื่อเด็กสลับแท็บหรือเปิดแอปอื่น ระบบจะส่งเสียงสัญญาณเตือน พร้อมนับจำนวนครั้งที่ออกจากหน้าจอและแจ้งเตือนคุณครู

6. **ระบบไลฟ์หน้าห้อง (Interactive Projector & WordCloud):**
   - โหมดขึ้นจอใหญ่โปรเจกเตอร์ พร้อม **QR Code** และ **Room PIN** ให้นักเรียนสแกนเข้าร่วม
   - **Live WordCloud:** แสดงคำตอบสั้นๆ ท้ายคาบ ขนาดตัวอักษรปรับตามความถี่คำ
   - **Live Poll:** โหวตโพลล์คำถามสดหน้าห้อง แสดงสัดส่วนเปอร์เซ็นต์แบบเรียลไทม์

7. **ระบบเช็คชื่อเข้าเรียน (Attendance Management):**
   - บันทึก มา / สาย / ลา / ขาด อย่างรวดเร็ว มีปุ่มลัด **"มาครบทุกคน"**
   - สรุปสถิติประจำวัน และส่งออกข้อมูลเป็น **CSV**

8. **ผังห้องเรียนจำลอง & แจกคะแนนพิเศษ (Seating Grid Management):**
   - จำลองตำแหน่งโต๊ะนั่งเรียนจริงตามแถวและคอลัมน์
   - คลิกที่โต๊ะนักเรียนเพื่อแจกคะแนนพฤติกรรมเชิงบวก (+1, +2, +3, +5 EXP) พร้อมเสียงเหรียญ

9. **ระบบแชร์ผลงาน (Classroom Gallery & Peer Review):**
   - แกลเลอรีจัดแสดงผลงานของนักเรียน
   - เปิดให้เพื่อนๆ เข้ามากดหัวใจ (❤️) และเขียนคอมเมนต์เชิงบวกให้กำลังใจกัน

10. **ตู้กาชาปองสุ่มชื่อ & เครื่องมือแบ่งกลุ่ม (Randomizer & Groups):**
    - ตู้กาชาปองแอนิเมชัน หมุนคันโยกแล้วลูกแก้วตกลงมาสุ่มชื่อนักเรียนตอบคำถาม
    - ระบบแบ่งกลุ่มนักเรียนตามจำนวนกลุ่มที่ต้องการแบบเท่าๆ กัน

11. **Dual Role Switcher & LINE OA Simulator:**
    - สลับมุมมองได้ทันทีระหว่าง **"หน้าครู (Teacher Dashboard)"** และ **"หน้านักเรียน (Student LIFF)"**
    - จำลองหน้าจอสมาร์ตโฟนแสดงการ์ด LINE Flex Message สมจริง
    - สลับธีมมาสคอตได้ระหว่าง **คุณหมู 🐷** และ **คุณไก่ 🐔**
